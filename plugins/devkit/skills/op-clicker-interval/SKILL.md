# op clicker interval

Окно OP Auto Clicker 4.0: поля hours, mins, secs, milliseconds (Win32; UI Automation пустой). Настройки не сохраняются между запусками. Start не нажимать без просьбы.

## Как выполнить
Вызови ИНСТРУМЕНТ run_skill с аргументами: name = "op-clicker-interval", args = '{"secs": 1, "ms": 0}' (подставь нужные значения). Не пиши это как код и не вызывай pc_script.
Меняет ПК — система сама спросит «да».
