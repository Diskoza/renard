# Документы, презентации, таблицы

## Сначала содержание, потом оформление
1. Уточни (или возьми по умолчанию): тема, язык (школа — польский), объём, для кого.
2. Собери материал (навык research), составь план разделов.
3. Только потом создавай файл через pc_script (python-docx / python-pptx / openpyxl) и сохрани в workspace\docs.
4. Открой результат и проверь: нет пустых слайдов, текст не вылезает, формулы в таблице считаются.
5. Ответь коротко, файл покажется в чате карточкой.

## Школьный документ
Титульный лист: название школы, тема, имя и фамилия, класс, дата.
Шрифт 12 pt, межстрочный 1,5, поля 2,5 см, нумерация страниц, в конце Bibliografia (реальные ссылки).
Sprawozdanie z ćwiczenia: Cel → Wykonanie (kroki, zrzuty ekranu) → Wyniki → Wnioski.

## Презентация
- 1 мысль = 1 слайд, на слайде ≤ 5 пунктов по ≤ 8 слов; подробности — в заметки докладчика.
- 8–12 слайдов на 5–7 минут. Первый — тема и автор, последний — выводы/вопросы.
- Картинки только реальные (его файлы или найденные), не выдумывай подписи к ним.

## Таблица
- Заголовки в первой строке, закрепить их; числа — числами, не текстом.
- Итоги — формулами (=SUMA/=SUM), а не посчитанными вручную числами.
