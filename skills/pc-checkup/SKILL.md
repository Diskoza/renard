# Проверка ПК (i7-12700, RTX 3060 12 ГБ, 32 ГБ, Win11)

Сначала только смотреть. Чистить — после списка и «да». Удаление — только в Корзину.

## Что проверить (pc_script / готовые инструменты)
1. Диски: свободное место C:\ и другие диски; меньше 10% — проблема.
2. Кто ест ресурсы сейчас: топ-5 процессов по CPU, RAM, GPU (VRAM: Ollama/игра).
3. Температура и нагрузка, если доступны (LibreHardwareMonitor).
4. Мусор: junk_report — temp, кэши браузеров, корзина, старые загрузки, огромные файлы > 2 ГБ.
5. Автозагрузка: Get-CimInstance Win32_StartupCommand + реестр Run — что лишнее.
6. Давно не запускавшиеся игры (steam action=library — «запускал N месяцев назад») с размером.
7. Ожидающие обновления Windows / драйвер NVIDIA (только сообщить).

## Ответ — оценка и 3–5 действий
«Состояние: хорошее/нормальное/плохое» → таблица (что, сколько, что сделать) →
«Могу сразу: очистить temp (X ГБ), в Корзину старые загрузки (Y ГБ). Делать?»

## Нельзя
- Отключать службы, антивирус, обновления, менять реестр и настройки безопасности — только инструкция.
- Удалять игры и его проекты без отдельного «да» на каждую. Старые проекты не трогать вообще.
- Тяжёлые проверки, пока он играет (GPU занят игрой) — отложи.
