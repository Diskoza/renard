# Отладка кода

## Цикл (как у опытного разработчика)
1. **Воспроизведи.** Запусти (pc_script / команда) и получи точный текст ошибки. Не гадай по описанию.
2. **Прочитай ошибку снизу вверх**: последняя строка — что случилось, строка с его файлом — где.
3. **Одна гипотеза → одна проверка.** Добавь print/лог или маленький тест, проверь именно эту гипотезу.
4. **Минимальная правка** причины, а не симптома. Не переписывай весь файл.
5. **Запусти снова** и убедись, что ошибка ушла и ничего рядом не сломалось.
6. Ответ: что было причиной (1–2 предложения) → исправление (diff или блок кода) → как проверил.

## Прислал файл с кодом: «почини / поправь»
1. Прочитай файл целиком (read_file). Пройди **каждую функцию по очереди** и выпиши ВСЕ ошибки — код может падать на
   первой строке и скрывать остальные, поэтому ищи и по чтению, не только по первой ошибке запуска.
   Проверяй: опечатки в именах, неверные пути/папки (создаётся одна, пишется в другую), расширения файлов,
   off-by-one в range, `=+` вместо `+=`, обмен без кортежа, return внутри цикла, изменяемые аргументы по умолчанию,
   global, деление на ноль, str + int, input() без int().
2. Сохрани исправленный файл РЯДОМ с оригиналом: `<имя>_fixed.<расширение>` (write_file). Оригинал не трогай.
3. Проверь: run_command `python -m py_compile "<файл>_fixed.py"`; если программа не ждёт ввода/сети — запусти её
   (timeout 20) и посмотри вывод. Ошибка — исправь и проверь снова.
4. Ответ: таблица «где → что было → как исправил», ссылка на файл, как проверил. Весь код в ответ не вставляй —
   он в файле (покажи только самые важные места). Что требует его решения (токен, пути) — отдельной строкой.

## Частые причины
- Python: ModuleNotFoundError — не тот venv (pip install в .venv); KeyError/None — данных нет, проверь вход;
  UnicodeEncodeError на Windows — PYTHONIOENCODING=utf-8 или sys.stdout.reconfigure(encoding="utf-8").
- JS/TS: undefined — асинхронность (забыт await), неправильный путь импорта, CORS — сервер, а не фронт.
- PowerShell: кавычки и $ внутри строк — выноси код в файл .ps1/.py вместо однострочника.
- «Порт занят» (EADDRINUSE) — найди процесс: Get-NetTCPConnection -LocalPort N.
- Работало и сломалось — что менялось последним (git diff, git log -3).

## Нельзя
Удалять файлы, делать git reset --hard / push без «да». Изменения — только в его проекте, о котором речь.
