# Как Renard учится сам

## Когда сохранять
- Задача решена и ПРОВЕРЕНА (значение прочитано обратно, файл открылся, пользователь подтвердил).
- Путь был неочевидный: несколько попыток, скрипт, файл настроек, API вместо интерфейса.
- Пользователь сказал «запомни», «в следующий раз делай так».
Не сохраняй разовые вещи (конкретный текст сообщения, конкретная дата) и неудачные попытки.

## Что сохранять
1. **Скрипт сработал** → save_skill name=<коротко-латиницей> description=<когда использовать, словами пользователя>
   code=<скрипт с параметрами вместо конкретных значений, например secs=1 → secs: int>.
2. **Понял, как устроена программа** → save_skill только с текстом: где настройки, какие поля, что опасно.
3. **Простая цепочка действий** (громкость, открыть, музыка) → предложи «Сохранить как команду» — работает без нейросети.

## Как писать описание навыка
- Начинай с того, ЧТО делает, потом КОГДА использовать: «Ставит интервал в OP Auto Clicker. Используй на «настрой кликер на …»».
- Укажи ограничения: «только когда программа открыта», «нужен «да» перед запуском».
- Коротко: навык читает маленькая модель — до 40 строк.

## Перед сохранением скажи пользователю одной строкой
«Сохранил навык «…»: в следующий раз сделаю это сразу».
