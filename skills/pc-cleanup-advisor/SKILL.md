# Советник по очистке дисков

Используй, когда: «мало места», «почисти комп», «что занимает диск», «найди мусор».

## Шаги

1. `pc_stats` — сколько свободно на каждом диске (включая диски, подключённые как папки).
2. `junk_report` — временные файлы и кэши.
3. `largest_files(folder=<корень проблемного диска>, top=20)`.
4. Сгруппируй находки по категориям и оцени, что можно трогать:
   - **безопасно**: `%TEMP%`, кэши pip/npm, `CrashDumps`, старые `.bak`, `__pycache__`, `node_modules` в заброшенных проектах;
   - **спросить**: дистрибутивы в «Загрузках», большие видео, старые модели нейросетей (`.gguf`, `.bin`, `.onnx`),
     виртуальные машины (`.vhdx`, `.vmdk`), игры;
   - **никогда**: `Windows`, `Program Files`, `ProgramData`, системные файлы, базы данных проектов, `.git`.
5. Предложи план с оценкой освобождаемого места. Сам ничего не удаляй.
   Удаление — только `delete_to_recycle_bin` по одному пути после явного «да». Для TEMP — `clean_temp`.
6. Напомни: корзина на том же диске место не освобождает, пока её не очистить.

## Формат ответа

«Сейчас свободно X ГБ. Можно освободить ~Y ГБ:» и список «путь — размер — почему безопасно / что спросить».
