# Рецепты фото

Сразу вызывай нужный инструмент. look_at_image перед обработкой НЕ нужен: инструменты сами смотрят на фото
(лица, свет, резкость). Смотреть картинку — только если он спрашивает «что на фото» / «как тебе».

| Просьба | Что вызвать |
|---|---|
| обработай / сделай красиво / улучши / цветокор / свет и тени | photo_fix path=… (ночные с огнями — style=night; «теплее» — warm; «сочнее» — vivid; «чб» — bw) |
| затемни светлые фото | photo_fix darken=yes |
| светлый пол / плитка отвлекает | photo_fix floor=yes |
| выбери лучшие из серии / папки | photo_best folder=… (n=сколько) |
| под Instagram пост | photo_crop ratio=4:5 (обработать и обрезать сразу — photo_fix ratio=4:5) |
| под сторис / reels / TikTok | photo_crop ratio=9:16 |
| смазано ли / что не так с фото | photo_info |
| перерисуй руку / убери человека / замени предмет | photo_mask (он закрашивает кистью) → после его ответа photo_ai what=fix/remove/replace prompt=по-английски |
| убери фон | image_edit ops=remove_bg (белый фон — remove_bg white) |
| увеличь качество / разрешение | image_edit ops=upscale 2 (маленькое фото — upscale 4) |
| аватарка | image_edit ops=square; fit 512x512; circle |
| аватарка без фона | image_edit ops=remove_bg; square; fit 512x512 |
| стикер Telegram | image_edit ops=remove_bg; fit 512x512 (сохранить .png или .webp) |
| обложка YouTube | image_edit ops=aspect 16:9; width 1280 |
| ретро | image_edit ops=sepia; vignette; contrast 10 |
| скрыть лицо / номер | image_edit ops=pixelate <область> (10%,10%,40%,40% или top/center) |
| мем | image_make kind=meme top=… bottom=… |
| коллаж | image_make kind=collage paths=a.jpg;b.jpg;c.jpg |
| уменьшить вес для отправки | image_edit ops=fit 1920x1920 (сохранить .jpg) |

## Правила
- «Это фото» = последнее, которое он прислал или о котором говорили. Можно передать и ПАПКУ — обработаются все фото.
- Оригинал не трогается: результаты в папках edited / best / crop рядом с фото.
- Ответ короткий: что сделал. Картинки (до/после) сами покажутся в чате, пути расписывать не нужно.
- Не уверен, что понравится — предложи другой стиль или strength 0.6 / 1.4.
- Чужие лица на публикацию — только размыть/пиксели; клонировать голос/лицо без разрешения нельзя.
