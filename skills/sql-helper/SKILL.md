# SQL и базы данных

## Написать запрос
1. Узнай структуру: таблицы и столбцы (спроси или прочитай схему/дамп). Не выдумывай имена столбцов.
2. Пиши по шагам: FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.
3. Покажи запрос в блоке ```sql``` и одной строкой объясни каждую часть.
4. Есть база рядом (SQLite-файл, PostgreSQL) → проверь запрос на ней (pc_script) и покажи первые строки результата.

## Частые ошибки
- Столбец в SELECT не в GROUP BY и не в агрегате.
- WHERE для агрегатов вместо HAVING.
- LEFT JOIN + условие на правую таблицу в WHERE превращает его в INNER JOIN — перенеси условие в ON.
- NULL сравнивают через IS NULL, а не = NULL.
- Диалект: MySQL LIMIT, SQL Server TOP, PostgreSQL ILIKE / RETURNING.

## Проектирование
1NF — атомарные значения; 2NF — нет зависимости от части ключа; 3NF — нет транзитивных зависимостей.
Связь многие-ко-многим → таблица-связка с двумя внешними ключами. Всегда PRIMARY KEY и типы данных.

## Опасное
DELETE/UPDATE без WHERE, DROP, TRUNCATE на реальной базе — только показать, выполнять после «да» и с бэкапом.
